# 精靈與巨魔 — 原型（建築規格 V0.6 ＋ 角色設計 V0.7）

Godot 4.4 單機權威原型。純邏輯（`core/`）與畫面（`game/`）分開，日後把 `core/` 搬到權威伺服器即可，畫面只送指令。

## 試玩版

開啟後先選模式：**扮演精靈**（另外兩名精靈與巨魔由電腦控制）、**扮演巨魔**（三名精靈由電腦控制）、**自由測試**（可切換所有角色，含測試工具）。

- 網頁版（手機橫放用瀏覽器開）：`gh-pages` 分支就是匯出好的網頁版。到 GitHub 的 Settings → Pages，Source 選 `Deploy from a branch`、Branch 選 `gh-pages` 後，網址是 `https://devil10421-source.github.io/trollvself/`。
- 重新匯出：安裝 Godot 4.4 的 Web 匯出樣板後執行
  `godot --headless --path . --export-release "Web" build/web/index.html`，再把 `build/web/` 的內容放到 `gh-pages` 分支。
- 美術是原創造型的 SVG（`art/sprites`，由 `tools/gen_art.py` 產生），中文字型是 Noto Sans TC 子集（`tools/build_font.py`）。

**試玩版相對於設計文件的調整**（都在 `data/` 裡，可改回）
- 在樹屋內也能建造／升級基地內（樹屋 11 格內）的建築：`house.build_from_inside`。原因：模擬顯示被圍攻的精靈如果不能蓋東西就只能等死。設成 `false` 就回到「屋內不能施工」。
- 巨魔前期變弱、升級變慢（Lv1 1,200 HP／30 傷害；經驗 = 有效傷害 × 0.3；殺精靈 +800），樹樁門 HP 加倍（2,000／4,000／7,000／12,000），箭塔傷害 20／45／90。
- 電腦精靈（`core/ai/elf_bot.gd`）對巨魔 AI 的模擬：精靈約 18 分鐘全滅、巨魔約 6:00 Lv4、12:00 Lv7。用 `tools/balance.gd` 可重跑。

## 怎麼跑

1. 用 Godot 4.4（或更新的 4.x）開啟這個資料夾，按 ▶ 執行。
2. 自動測試（不開畫面）：
   ```
   godot --headless --path . --script res://tests/run_tests.gd
   ```
   目前 41 項全部通過：規格 V0.6 第 7 節的 10 項必測，加上角色設計 V0.7 與試玩版的 18 項。
3. 整局冒煙測試（巨魔 AI 跑一整局，看有沒有執行期錯誤）：`godot --headless --path . --script res://tools/smoke.gd`

## 操作（手機 / 滑鼠皆可）

- **上方**：切換操控精靈 1/2/3 或巨魔（單機測試用），速度 x1/x4/x10、暫停、縮放、「找我」。
- **點空地**：移動。**拖曳**：移動鏡頭。
- **建造**：右側選建築 → 點地圖看綠/紅預覽 → 再點同一格或按「確認放置」。城牆會停留在建造模式方便連續放。
- **點建築**：看資訊，可升級／取消（顯示退款）／續建／修繕（顯示修滿費用）／拆除。
- **巨魔模式**：點精靈或建築＝攻擊，點空地＝移動；可關閉自動 AI。
- **測試工具**：加錢、跳到 12:00、跳到 24:50、巨魔立刻出場、重新開局。

## V0.7 角色設計（參考《猛鬼宿舍》）

**精靈**
- **樹樁門**：地圖 `D` 格，每個基地入口一扇，屬於最近的精靈。平常開著；主人進自己的樹屋就自動關上，擋巨魔也擋精靈。可被巨魔打破（HP 依樹屋等級 1,000／2,000／3,500／6,000），破門保持開啟直到修滿。
- **入屋**：右側「我的樹屋 → 進屋關門」。屋內不可被攻擊、金幣 +50%，不能施工；下其他指令會自動出屋。樹屋被毀會被彈出並暈眩 1 秒。
- **修復鈕**：「修復城牆」每按一次修 3 秒，修自己基地 HP 比例最低的城牆或樹樁門；冷卻轉圈圖示，速度與冷卻依樹屋等級（20/30/45/65 HP/秒，冷卻 6/5/4/3 秒）。
- **所有修復免費**。精靈手動修只限非城牆建築；跑速 5.0 格/秒；林影步取消。
- **靈魂**：修復之光、星光印記、藤蔓纏繞一開始都是 Lv1，每 90 秒 1 點可升到 Lv3。

**巨魔**
- 經驗 = 對建築的有效傷害（僕從造成的也算），殺原始精靈 +1,500；Lv1～Lv10。
- 巢穴每秒回 8%，巢外脫戰 6 秒後每秒 1%；死亡後 15 秒 + 每級 2 秒復活。
- 技能：回巢（引導 3 秒、受傷打斷、成功才進冷卻）、重擊（下一下 3 倍）、威嚇怒吼（Lv3，暫停施工與修復 1.5 秒、之後 5 秒修復 −30%，不影響傳送門）、狂暴（Lv6，8 秒攻速 +50%、受傷 +20%）。
- 僕從 = 主巨魔等級 −2、數值 45%，只有回巢與重擊。
- 測試用 AI：殘血 30% 回巢、補到 95% 再出發，會自己放技能。

**V0.7 推定（文件沒寫、先這樣做）**：靈魂的修復之光也能修城牆；怒吼後的修復減速持續 5 秒；入屋要走到樹屋 2 格內；樹屋被拆或被毀門就打開。

## 程式結構

```
core/defs      BuildingDefinition、DefinitionDB（讀 JSON 並驗證）
core/state     BuildingInstance、UnitState、PlayerAccount
core/grid      TileGrid（地形、占格、BFS）、GridMath（距離定義）
core/services  Economy / Building / Combat / Repair / Visibility / Escape / Match / Unit
               House（樹屋、入屋、樹樁門、修復鈕）/ Troll（等級、回血、技能）/ Soul（靈魂技能）
core/sim       MatchSim（10 tick/秒、submit 指令、request_id 去重）、EventBus
core/ai        ElfBot（試玩版的電腦精靈）
game/          main.gd（模式、觸控、HUD）、map_view.gd（建築/單位/特效）、terrain_layer.gd、fog_layer.gd、cooldown_ring.gd
art/           原創 SVG 美術與中文字型子集
tests/         自動測試
tools/         screenshot.gd、smoke.gd、balance.gd（電腦對戰時間軸）、gen_art.py、build_font.py
```

每 tick 順序：巨魔出場 → 視野 → 樹樁門開關 → 單位移動與攻擊 → 巨魔回血與回巢 → 靈魂點數 → 建築施工 → 傳送門施工 → 修繕 → 樹屋修復鈕 → 塔攻擊 → 每秒產量 → 勝負判定（規格第 5 節順序）。

## 規格沒寫清楚、目前採用的預設

1. 施工中普通建築從 10% HP 隨進度長到滿；施工中受的傷會保留到完工。
2. 普通建築的建造與升級都要擁有者在 2 格內施工，別人不能代蓋；走開或接新工作就暫停，可按「續建」。
3. 城牆擋所有單位（含精靈）；建傳送門只檢查發起者走得到門 3 格內。
4. 傳送門每階段完成後停住，由任一存活精靈按「支付下一階段」付款。
5. 多人施工：2 人 +15%、3 人以上 +30%。施工範圍＝所在格到門的 Chebyshev 距離 ≤ 3。
6. 傳送門前置的大廳 Lv2、樹屋 Lv4 都看發起者自己的。
7. 冰霜塔單體施放，選敵同箭塔。
8. 升級中取消也套 50% 公式；完工後拆除不退款。
9. 所有建築升級都保留血量比例（規格只寫城牆）。
10. （V0.7 已改）修復全部免費。
11. 修繕站對靈魂修復與樹屋修復鈕同樣加速；+25% 只取一座，不疊加。
12. （V0.7 已改）巨魔死亡 15 秒 + 每級 2 秒後在巢穴復活。
13. 測試用巨魔 AI 會在「最近的精靈」與「最近的可攻擊建築」之間挑路徑成本最低的，精靈成本打 6 折；牆擋路就先打牆；屋內精靈不算目標。它不是正式 AI。
